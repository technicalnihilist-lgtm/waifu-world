GitHub Actions runner (Ubuntu, Xvfb, Mesa llvmpipe). They are real frames from

## Regenerate

Anywhere with a display:

```bash
godot --path . --resolution 720x1280 tools/capture_screens.tscn
```

Headless machine or CI:

```bash
Xvfb :99 -screen 0 720x1280x24 &
DISPLAY=:99 LIBGL_ALWAYS_SOFTWARE=1 godot --path . --resolution 720x1280 tools/capture_screens.tscn
```

PNGs land in `user://screenshots/`. On GitHub, just run the **screenshots**
workflow — it captures them and commits the result here.

## Note on the renderer

These come from Mesa's software rasteriser (llvmpipe), which is slower than a
phone GPU but pixel-accurate for the Compatibility renderer this app ships.
